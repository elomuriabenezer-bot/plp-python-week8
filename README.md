# Final Project: Personal Mini-Toolkit

This menu-driven Python program offers a number guessing game, a to-do list, and a simple calculator. The menu returns after each tool and handles choices that are not on the menu with a friendly message.

## Files

- `toolkit_plan.txt`: plan for the tools, concepts, and menu text.
- `toolkit.py`: the menu and three interactive tools.
- `screenshots/`: add screenshots of the menu, invalid choice, and each tool in action.

## How to Run

Open a terminal in this folder and run:

```powershell
python toolkit.py
```
